# 산업안전기사 필기 CBT — 기획안 v2

작성 2026-10-22 · 이전 기획안: `CBT_기획안_최종본.md` (기술 구조·채점 규칙은 그대로 유지)

## 1. 결정 사항 (사용자 확정)

| 항목 | 결정 |
|---|---|
| 종목 | 산업안전기사 **필기** 집중 |
| 제공 형식 | 필기 CBT(자동 채점) + 문제지 PDF |
| 콘텐츠 출처 | 3001 LABS 자료, 공개 기출 직접 입력, 자체 제작 모의고사, 다른 사이트·블로그·카페 추가 조사 |
| 수익 | 애드센스 광고만 · 회원가입 없음 |

## 2. 목표

- 검색으로 들어온 수험생이 **회차 목록 → CBT 풀기 / 정답·풀이 보기 / PDF**로 바로 이어지는 사이트
- 핵심 지표: 월 방문자, 방문당 페이지 수(광고 노출), 공개 해설 페이지 검색 노출 수

## 3. 콘텐츠 전략

### 3.1 출처별 기준

| 등급 | 출처 | 게재 방식 | 확인할 것 |
|---|---|---|---|
| A | 자체 제작 모의고사 | 출제기준·법령 근거로 새로 작성, 사람 검수 후 게재 | 법령 수치·정답 검수 |
| B | 3001 LABS | **이용 허락 범위 안에서만** 게재, 출처 표기 | 허락 범위(필기 2회분 외 반복연습 33세트 포함 여부) |
| C | 한국산업인력공단 공개 기출 | 원문 입력, 해설은 자체 작성 | 공개 범위·이용 조건(큐넷 공지 확인) |
| D | 다른 사이트·블로그·카페 | **그대로 옮기지 않음.** 허락받은 자료만 게재. 그 외는 출제 경향 참고용 | 운영자 허락 여부 |

- 필기는 2022년 하반기부터 CBT(문제은행)로 바뀌어, 이후 회차는 공식 기출이 없고 "복원" 자료만 있습니다. 복원 자료의 권리는 만든 곳에 있으므로 D와 같게 다룹니다.
- 해설은 출처와 관계없이 **자체 작성**을 원칙으로 합니다(검색 노출·중복 콘텐츠 측면에서도 유리).

### 3.2 출처 조사 (1단계 작업)

- 대상: 큐넷, 출판사 공개 PDF, CBT 사이트, 블로그·카페
- 산출물: 출처 목록(회차·문항 수·해설 유무·이용 조건·연락처) → 게재 가능 / 허락 요청 / 참고만으로 분류
- 허락 요청이 필요한 곳은 문의 문안을 만들어 드리고, 발송은 사용자가 합니다.

### 3.3 목표 분량

| 시점 | 회차 수(120문항) |
|---|---|
| 1차 개편 | 현재 3회 + 3001 허락분 + 공개 기출 확보분 |
| 이후 | 자체 제작 모의고사 매달 1회 이상 |

## 4. 사이트 구조

```
홈
├─ 연도별 회차 목록 (연도 접기/펼치기, "2025년 전체 페이지 →")
│   └─ 회차 줄: [회차 태그][출처 태그: 기출/복원/모의고사] 제목 · 날짜 · 문항 수
│       버튼: 문제지 PDF | CBT 시작 | 정답·풀이 보기
├─ 과목별 학습 (과목 선택 → 해당 과목 문항만 풀기)
├─ 랜덤 모의고사 (전체 문항에서 과목별 20문항씩 무작위 120문항)
├─ 내 기록 / 오답 다시 풀기 (쿠키 기반, 현재 기능 유지)
└─ 공개 해설 페이지 /p/회차/쪽 (5문제씩, 검색 유입용)
```

| URL | 내용 |
|---|---|
| `/` | 최근 회차 + 연도별 목록 |
| `/y/2025` | 연도 전체 페이지 |
| `/p/:회차`, `/p/:회차/:쪽` | 정답·풀이 보기(공개, 5문제씩) |
| `/pdf/:회차.pdf` | 문제지 PDF(정답표는 마지막 쪽) |
| `/s/:회차` | 과목별 풀기 |
| `/random` | 랜덤 모의고사 |

### 4.1 회차 메타데이터 추가

`year`, `round`, `kind`(기출 / 복원 / 모의고사 / 반복연습), `sourceNote`, `pdfReady`

## 5. 문제지 PDF

- 배포할 때 GitHub Actions에서 Playwright로 인쇄용 페이지를 PDF로 만들어 정적 파일로 올립니다.
- 비용: GitHub Actions 무료 한도 + Cloudflare 현재 플랜. 추가 비용 없음.
- 구성: 표지(회차·출처) → 문제(2단) → 정답표

## 6. 광고

- 현재 배치 유지: 목록·해설 페이지 콘텐츠 사이 광고, 페이지 이동 시 전면 광고 허용
- 회차 목록이 길어지므로 목록 6~8줄마다 광고 1개
- 원칙: 버튼 바로 옆에는 두지 않음(실수 클릭 방지)

## 7. 검색 노출(SEO)

- 페이지 제목 예: "산업안전기사 필기 2025년 3회 복원 문제 해설 1~5번"
- 연도 페이지·회차 페이지마다 고유 설명문, sitemap 자동 갱신
- 같은 문항 묶음을 쓰는 반복연습 세트는 공개 해설 페이지를 만들지 않음(중복 콘텐츠 방지, CBT 풀기만)

## 8. 기술

- 유지: Hono + Cloudflare Workers + D1, main 병합 시 자동 배포
- 추가: 회차 메타데이터 컬럼, 연도 목록·랜덤 모의고사 API, PDF 생성 단계
